# Minecraft Forge 1.20.1 – Home Assistant Add-on

Minecraft-Java-Server mit Forge 1.20.1 für Home Assistant (amd64 / aarch64).

## Installation

**Lokal:** Den Ordner `minecraft_forge_1_20_1` über Samba in den Ordner `addons` kopieren, dann in Home Assistant unter *Einstellungen → Add-ons → Add-on-Store → ⋮ → Nach Updates suchen* das Add-on installieren.

**Per Repository:** Dieses Repository (als Git-Repo) unter *Add-on-Store → ⋮ → Repositories* hinzufügen.

Details und Optionen stehen in `minecraft_forge_1_20_1/DOCS.md`.

## Hinweis

Die Forge-Version (`forge_version`, Standard `47.3.0`) sollte man vor dem Einsatz auf https://files.minecraftforge.net prüfen und ggf. auf eine aktuelle 1.20.1-Version setzen.
